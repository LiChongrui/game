# 水滴合成深海 · Merge Ocean

原创合成小游戏（Web 版 + 微信小游戏版）——同种水滴相融合成，从雾泡一路汇入深渊王座。

**在线试玩：<https://game.luosgeo.com>**

## 玩法

- 开始界面点击「开始游戏」进入对局；点击/拖动投放水滴，同种水滴相遇即合成下一级（雾泡 → 水滴 → 露珠 → … → 沧海）。
- **开局即无尽模式**：周期潮汐、礁石障碍、雨云/漩涡/冰晶等 13 种特殊水滴随海域逐级解锁，渐进加压越玩越狂。
- 四大技能（换滴 / 涟漪 / 蒸发 / 水流）：合成带**符文**的水滴充能，任务完成直接充满。
- 堆高超警戒线判负；潮汐浮起的滴水永不漫线，但会抬高堆体。
- 8 大海域按累计得分演进（背景主题色随之渐变切换），海域图鉴/成就/每日/榜单双入口独立面板。
- **深渊潜航**（二周目）：免累计分解锁门槛，经菜单「每日挑战」进入，选海况词缀开更高难度高分局。

## 运行

纯静态页面，零依赖、零构建：

```bash
# 任选一种方式起个静态服务器
python -m http.server 8080
# 或 npx serve .
```

打开 <http://localhost:8080> 即可游玩；也可直接双击 `index.html`。

## 目录结构

```
├── index.html        # 入口页面
├── js/
│   ├── platform.js   # 平台适配层（Web/微信环境探测与存储差异封装）
│   ├── config.js     # 全部数值锚点（合成链/技能/海域/潮汐/词缀，一行可调）
│   ├── physics.js    # 自研圆形物理（子步进积分 + 冲量解算）
│   ├── core.js       # 画布自适应 / 存储助手 / 音效 / 广告占位
│   ├── systems.js    # 游戏主逻辑（状态/输入/合成/技能/潮汐/海域/图鉴数据）
│   ├── render.js     # 全部渲染（背景/水滴/HUD/面板/开始界面/结算）
│   └── main.js       # 主循环与启动
├── test/             # 回归链：simulate.js 蒙特卡洛模拟、v90_tide 潮汐验证、v95_menu UI 截图
├── wechat/           # 微信小游戏版（adapter 垫片复用同一套 js/，音效为离线合成 WAV）
└── tools/            # 辅助脚本（音效离线合成 gen-audio.js、wx 环境启动自检 test-boot.js）
```
